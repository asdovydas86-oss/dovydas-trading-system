## Findings

1. **A stale-bytecode hazard that nearly produced a false report.** A mutation probe replacing a
   substring with one of the **same length** leaves the restored file the same size, and CPython
   invalidates `.pyc` on `(mtime, size)` at **one-second** resolution — so a mutate → test → restore
   cycle inside one second leaves a **stale mutated `.pyc` behind a correct source file**.
   `inspect.getsource` showed the restored source while the interpreter ran the mutation, and a
   `sha256` over `src/**/*.py` reported `RESTORED EXACTLY` — **true and insufficient**. It produced
   one false survivor and would have produced false *kills* for every later probe. Campaign rewritten
   with `PYTHONDONTWRITEBYTECODE=1` and per-probe cache clearing, re-run from scratch, and the full
   suite and policy digest re-run on cleared bytecode. Recorded in `CURRENT_STATE.md` §0.1.
2. **One genuine test hole, found by a probe and closed.** `compute` and `compute_series` **share**
   the expression pairing a MACD line element with a signal element — which is the design — so a shift
   moves both together and latest-value parity, prefix stability *and* the histogram's internal
   consistency all keep passing while every point describes the wrong bar. Two tests now derive the
   expected value from the prices at that bar, through the shared EMA helper and none of the pairing
   logic.
3. **Four architecture guards fired on docstrings, and were obeyed rather than widened.** They scan
   for the *text* of an engine's package name outside its permitted consumers; the dashboard and the
   workspace import none of those packages and must not, so crediting them by module path in prose was
   the error. Attributions reworded. **No guard was relaxed.**
4. **One existing test still pinned a panel position its own docstring said it should not.** Its
   docstring already records that a fixed list failed once when Slice 4 inserted a panel; the last
   positional assertion became the ordering relation.
5. **The projection cost is ~1 % of per-symbol compute** (0.208 ms against a 20.6 ms three-view sheet
   build) and **0.9 KiB per symbol**, because objects are referenced and never copied — asserted with
   `is`, element by element.

  the refusal goes with it.

  would need an ADR, not a convenience.

  required. Invisible at the 500-bar production window, real under replay.
