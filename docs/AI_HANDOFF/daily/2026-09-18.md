## Architecture decisions

**No new ADR.** ADR-0033 already decided the semantics; this milestone's job was to implement them
and to record the owner's acceptance. Three implementation decisions worth carrying forward:

1. **Zones live on `StructureFacts`, built in `build_structural_facts`** — beside the level run they
   group and inside the composition root that already owns the feature registry. No second
   market-data pipeline, and the three roles are the sheet's own three roles.
2. **The engine is pure over `(levels, width_series, policy)`**, and a separate `zone_width_series`
   resolves the policy's feature name against the caller's registry. The width and the sheet's own
   ATR reading therefore come from **one** feature instance rather than two that agree.
3. **The admissible region is enforced, not documented.** `ZoneWidthPolicy` raises outside
   `[0.10, 1.00]`. The region is the one thing about `k` that was measured, and a bound written down
   but not enforced is a bound a later caller steps over without noticing.

**Deliberately NOT decided:** R3, R4, R15, where opportunity state lives, the phase-segmentation
model, the trendline-anchor rule, the divergence-alignment policy.

## Findings

1. **`python -m fmis.pipeline.cli` exits `0` and prints nothing.** `cli.py` has no `__main__` guard,
   so running the module as a script executes the imports and stops — a *silently successful* no-op
   that looks exactly like a crashed server. The working invocation is `.venv/bin/fmits`.
2. **Three architecture guards fired, and all three were obeyed rather than widened away.**
   - The level-crossing consumer guard was **widened with a named exemption** and the ADR
     justification its own docstring demands, and the direction rule it actually protects is now
     asserted in both directions.
   - The market-regime guard caught a **docstring** spelling a package path the package does not
     import — a text scan doing its job on prose that agreed with it. **The prose was corrected**, and
     the same list is enforced over the real import graph instead.
   - The dashboard contract guard — *"`sum`, `min`, `max` and `sorted` are how a presentation layer
     becomes an engine"* — caught the zone selection being sorted in `sections.py`. **It was right**:
     something must choose which nine of 250 bands a page shows, and the dashboard is the wrong
     place. The ordering moved onto `PriceZoneSet`, and the rendered output was verified
     byte-identical across the move.
3. **The no-width case is real in live data, not hypothetical.** Six of the twelve live role-views
   inspected carry 1–3 levels that formed **no** area, because they were confirmed before ATR(14)
   warmed up. The page states it with its reason. No zone was invented for any of them.
4. **Two bands opened by sibling levels on one bar can overlap**, and a later level inside both is
   claimed by whichever the level run produced first. This is the residual mechanism behind the
   admissible region's ceiling — report 0050 measured symmetry holding at `k ≤ 1.00` and failing from
   `1.25` — and it is now recorded as limitation **PZ-7** on the zone set itself rather than left in
   a report.
5. **The zone cost is 0.55 ms per symbol-role at the live window** — ≈33 ms for the whole 20-symbol
   watchlist, against a scan dominated by sixty network round-trips. **No cache was introduced**, and
   introducing one for a half-millisecond computation would trade a measured non-problem for a class
   of stale-state bug.
