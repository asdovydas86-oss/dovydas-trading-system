## The thing worth remembering from this session

**The placebo is the whole report.**

The raw return hazard to a real zone decays seven-fold over forty bars — `0.206 → 0.121 → 0.070 →
0.046 → 0.027 → 0.015` — steepest in the first three bars. Presented on its own that is a textbook
*"retests cluster within 2–3 bars"* chart and it would have yielded a confident `R4 = 3`, a
`ZoneInteraction` type, a retest window constant and a support/resistance label built on top of it.

**The placebo hazard is `0.207 → 0.122 → 0.072 → 0.045 → 0.026 → 0.015`.**

It is first-passage geometry, not market memory. The same trap caught R3: the persistence effect is
large, robust, holdout-confirmed — and identical on bands that no structural level anchored.

**Both of this gate's headline effects survive naive measurement and neither survives a control.**
Any future zone-interaction proposal must carry a null before it is discussed; ADR-0034 D5 makes
that binding.

## Defects found, and recorded rather than tidied away

1. **The research artifact was not reproducible, and the cause was mine.** `gzip.open` stamps the
   wall clock into the gzip header, so identical payloads hashed differently every run — three runs,
   three hashes. Caught only because determinism was **measured** across subprocesses rather than
   asserted in prose. Fixed with a `GzipFile(..., mtime=0)` writer. **This is the session's standing
   lesson and is recorded in `CURRENT_STATE.md` §0.1.**
2. **Five fixture expectations were wrong and the harness was right** — bar index confused with
   elapsed bars. The fixtures were corrected, not the code.
3. **Two verifier checks were too strict.** One treated `ABSENT → 1` at a prefix's final bar as
   repainting when it is history arriving; the other flagged 36 events whose `disp_atr` differed in
   the **13th significant figure**, because **ATR(14) is a recursive Wilder average with no finite
   warm-up** — a production property quantified here for the first time. No event changes
   displacement bin.
